Overview

My placement year.

Hawk-Eye is a sports technology company. During my placement I designed tools for the operators who run its systems at live events, working closely with product managers, developers and the operators themselves.

I worked on three tools. I've gone into most detail on the cricket no-ball panel, because it shows my whole process, from research to a finished product.

Project 01 / 03 · Cricket

Cricket “No Ball” Review Panel

When a no-ball is reviewed during a live match, an operator has to select the delivery, pick the type of no-ball, choose the batter and confirm the umpire's original decision, all before the replay goes out on TV.

I designed a new panel for this inside Hawk-Eye's existing cricket review system.

Problem

Operators have to make four decisions quickly, under pressure, before a no-ball replay can go out.

What I did

Talked to operators about what frustrated them, then improved the panel with their feedback.

Result

The panel is now used in the IPL.

Research

Talking to the operators.

I had calls with operators on Google Meet and messaged them regularly. I wanted to find out what they needed from a no-ball review and what annoyed them about the current process.

I then shared each version of the design with them and made changes based on their feedback.

Decision 01 / 04

Number the steps

What I found
The review always follows the same order, and it's easy to miss a step when you're working fast.
What I did
I numbered each step in the panel, so operators can always see what's left to do.
Decision 02 / 04

Warn before mistakes

What I found
Some information isn't available straight away during a live review.
What I did
Warnings show when something is missing, so it can be fixed before the replay goes out.
Decision 03 / 04

One decision at a time

What I found
Showing every option at once made it harder for operators to focus.
What I did
I grouped the options into four stages: the delivery, the no-ball type, the batter and the original decision.
Decision 04 / 04

Keep it familiar

What I found
Operators already use Hawk-Eye's review software every match.
What I did
I made the panel look and work like the rest of the software, so operators could pick it up quickly without extra training.
Outcome

Now used in the IPL.

The panel was added to Hawk-Eye's cricket review system and is now used in the IPL (Indian Premier League).

Project 02 / 03 · Basketball

Basketball Status API Feed Tool

A tool that lets operators update the status of live basketball games and report data problems as they happen.

See every game at onceEach game is a card showing its status, so operators watching several games can spot problems quickly.
Stay on the same screenUpdates open in a pop-up over the game list, so operators don't lose track of other games.
Separate tabs for separate jobsUpdating a game and reporting a problem are in different tabs, so each is simpler.
Confirm every changeA message confirms each update has gone through, because changes affect other systems.
Project 03 / 03 · Tennis

Tennis Logging Tool

A tablet app for coaches and players to set up training sessions and track drills, simple enough to use courtside.

Set up first, track secondEverything is set up before the session, so the tracking screen stays simple.
Step-by-step setupPlayers, rackets, drill type and court position are added one step at a time.
Made for tabletsBig buttons that are easy to tap quickly courtside.
Main actions stand outDuring a drill, the start, stop and end buttons are the most obvious things on screen.
